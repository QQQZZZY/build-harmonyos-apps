## 可以公开的范围

公开包包含插件清单、源码、网页、原生 Swift 源码、测试/fixture 源码、脚本、Skills、文档、图标、依赖锁文件与许可证。包内不包含 `node_modules`、`native/bin`、验收工程构建结果、运行记录、SDK、设备系统镜像或账户配置。

官方 Skills 的 Huawei MIT 版权和完整许可文本保持原样；自有 MIT 署名保持 `qu`。当前发布包没有第三方 HOScrcpy JAR。开源署名与项目名称不表示 Huawei 或 OpenAI 官方背书。

## 运行时数据边界

- 自有浏览器服务绑定 `127.0.0.1`，每次进程启动随机生成令牌，并检查 Host、Origin 和授权头。完整预览地址带令牌；不要公开仍在使用的地址。
- 窗口捕获包含所选模拟器窗口；HDC 截图包含设备当前显示内容。UI 树、Hilog、环境自检和错误信息可能包含个人文字、应用内容、设备名称及本机路径。
- 自有设备服务通过本地浏览器与 stdio MCP 返回这些结果；MCP 调用宿主会收到请求的设备数据。源码中未发现自有遥测或主动上传截图/日志的外部端点。
- 初次安装 Node 依赖和官方 CLI 的部分能力需要联网。该检查没有审计官方 CLI、Codex 或其他宿主的内部数据处理，不能据此声称整个工具链完全离线。
- 操作记录有界且不含输入全文；应用记录仅保存在本进程内存。HAP上传只写入本进程独占的临时文件，安装后清理。浏览器成功提示不显示临时安装路径；CLI/MCP错误或诊断仍可能包含路径。
- 正常停止预览会删除本进程临时捕获目录；强制终止或系统崩溃可能留下临时文件。手动截图、原生检查和 E2E 的持久结果由使用者自行管理，分享前需重新审查。

## 检查方法与限制

检查了公开文件中的个人绝对路径、邮箱、常见令牌/私钥特征、非空凭据赋值和带令牌的本地预览 URL；对最终归档逐文件重新扫描，并断言归档内容、文件所有者及元数据边界。对两个插件清单和 MCP JSON 作解析检查，确认保留署名、相对入口和官方上游许可证。

本轮检查覆盖现有公开源码、当前提交差异和新归档；0.1.2 首次公开提交已使用清理后的源码。此次不审计 GitHub 外部历史、旧发布件或外部平台记录。基于规则的扫描可能漏掉非标准格式的秘密。后续加入账号配置、真实设备素材或生产日志后需要再次检查；当前结论仅适用于本次核验的公开文件和归档。

0.2.0修改了工作台与设备适配代码，完成18项自动检查和真实HDC端到端交互；0.2.1只调整网页表现并完成桌面/窄屏与实际交互检查。功能证据与未验收项见 [validation.md](validation.md)。
